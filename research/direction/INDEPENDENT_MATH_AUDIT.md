# Independent adversarial mathematical audit

6 November 2026. This audit started from the equations and literal input/output tables rather than accepting prior checks. Its executable companion is [independent_audit_checks.py](independent_audit_checks.py), with machine-readable results in [independent_audit_results.json](independent_audit_results.json). It is a correctness audit of this explicitly bounded model, not a claim of novelty, speedup or formal verification.

## Verdict and exact scope

No counterexample was found to the deletion-mask construction, global-unrounded certificate calculation, fixed-tree nonnegative interval prefix, fixed-complete-group capacity bound, or block replay under the documented assumptions. These mechanisms have direct induction arguments below. The executed searches provide additional falsification evidence; their passing does not prove the general statements.

The contract requires integer `0<A<D`, integer `0<=rho<D`, unsigned integer `x,s` in `[0,H]`, fixed coefficients, known initial state, exact floor division, and enough intermediate width. Prefix products use nonnegative affine parameters and the specified fixed tree. A queried summary must be supplied an entry in the exact inclusive domain used to build it. The infinite-group capacity theorem additionally requires one fixed block length, one fixed number of complete blocks per group, the specified precision and topology, and quantized upper group gain strictly below one. Partial final blocks/groups are covered by per-instance certificates and exact replay, but the stated uniform constants are not automatically reusable for them.

## Independent expected values

The checker obtains each expected block map by literally executing the original floor recurrence for **every integer candidate** in its certified entry domain. It obtains the expected output mask from adjacent differences of this table, never from the subject's deletion-rank formula. Its primitive tests include signed bases and innovations, every small bit mask, and several negative and exact-divisibility boundary cases. It separately uses `Fraction` to compute exact unrounded affine trajectories and enclosures.

The tape tests exhaust all three-event inputs from a two-bit alphabet for every coefficient and offset with `2<=D<=5`, both extreme initial states, coarse precisions, unequal final block lengths and non-power-of-two group sizes. Seeded extra cases include extreme and random inputs, offsets `0` and `D-1`, denominators up to 1000, high retention and coarse scale. Explicit larger cases cover a 12-bit coarse predictor and a 32-bit state with retention `65535/65536`. All domain candidates are compared, including candidates other than the actual state. Replay is compared at every event.

For selected one-bit configurations, the checker also constructs the finite directed graph of predictor carry intervals, starting at every legal point initial state. Each edge corresponds to **every possible complete input group**. It checks exact rational affine extrema and the reported mask cap, adds each previously unseen carry interval, and runs until closure. For these particular configurations this checks every future group count, rather than merely sampling a long finite tape. It does not extend this finite-state result to other coefficients or precisions.

The executed run passed 17,780 primitive cases (107,660 entry comparisons), 15,962 traces, 319,974 full block-map candidate comparisons, 44,906 rational boundary checks and 58,766 output replay comparisons. The 24 closed carry graphs contain 971 reachable carry intervals and 10,090 checked edges. Each edge checks both exact rational predictor-width bounds and rational affine endpoint enclosures. Seven invalid-input regressions are also checked in a separate `python -O` process, including rejection of substituted summary-domain metadata and overlarge mask allocation, along with retention of a finite exact capacity bound whose float display overflows.

## Mathematical obligations checked by derivation

1. **Invariant unsigned interval.** The original update numerator lies in `[0,D*H+rho]`. Because `rho<D`, its floored quotient lies in `[0,H]`. The unrounded recurrence has the separate invariant interval `[0,S]`, where `S=H+rho/(D-A)`; the distinction matters when bounding predictor errors.
2. **Global rounding error.** With `e=z-s`, one step gives `e_next=(A/D)e+epsilon` with integer-machine residue `0<=epsilon<=(D-1)/D`. Starting from a point gives `0<=e_n<=((D-1)/(D-A))*(1-(A/D)^n)`. Using the larger time-independent bound is safe. This proof uses integer coefficients; replacing them with merely order-compatible floating values is insufficient.
3. **Certificate endpoints.** Exact `s` is at least `ceil(zlo-G)` and at most `floor(zhi)`. Intersecting with `[0,H]` preserves membership. Its number of adjacent boundaries, `hi-lo`, is at most `floor(G+zhi-zlo)`. The mask has `hi-lo` bits and represents `hi-lo+1` candidate entries; conflating these counts would be an off-by-one error.
4. **Mask preservation.** The initial table consists of consecutive integers. A floor-affine map with `0<A<D` is monotone and its adjacent differences are zero or one. Therefore any composed table still has this representation. Its image is consecutive, even if the entry increments are sparse. Computing the next base by `divmod` is valid for signed bases and innovations because Python's remainder remains in `[0,D-1]`.
5. **Deletion ranks and simultaneous removal.** Writing the image offset as `j`, the auxiliary floor is `floor((r-(D-A)*j)/D)`. Its downward crossings occur at exactly the documented ranks. Since `0<D-A<D`, one adjacent image increment cannot lose more than one unit. The number of crossings through image width `k` is `ceil(((D-A)*k-r)/D)`, hence at most `ceil((D-A)*k/D)`. All ranks refer to the old increment list; mutating that list before processing later ranks would select the wrong original boundary.
6. **Fixed-tree interval prefix.** Nonnegative coefficient and offset intervals can be multiplied outward with endpoint products. Composition of exact affine maps is associative; composition of rounded interval enclosures need not be. Correctness follows by induction on the actual tree nodes, so reassociation requires checking the newly used tree. Hillis–Steele's snapshot of the previous level avoids within-level dependency corruption. This argument covers non-power-of-two `P` as well.
7. **Uniform offset width.** For local offset interval width `w` measured in fixed-point integer units, `ceil(A*w/D)+1` is sufficient. At a composition node, the lower before-offset endpoint is at most its exact offset and hence at most `S`. Splitting the endpoint-product difference therefore gives `g_after_hi*E_before + (g_after_hi-g_after_lo)*S + E_after + 2/Q`. This does not require the **upper** before-offset endpoint to be at most `S`.
8. **Infinite fixed-group carry.** The same splitting uses the carried lower endpoint `<=z<=S`. Thus `E_next<=u*E+delta`, with exact rational `u<1`. From the initial zero width, `E<=delta/(1-u)` follows inductively for every number of fixed complete groups. Within-group prefixes use this carry bound once and then add `G` once. Repeatedly adding `G` to the carried unrounded interval would instead be unjustified. A rounded gain upper endpoint equal to one defeats this sufficient geometric bound even when the true gain contracts.
9. **Exact replay.** Induct on blocks: the certified map agrees with the serial block function at every entry in its domain; querying the actual entry yields the serial exit. Replaying the original recurrence from each resolved entry reproduces every intermediate state. Certificate computation and summary construction do not need the actual serial trajectory; the serial oracle appears only in validation.

## Defects found in the initial implementation

These were implementation defects or unsupported API behavior, not counterexamples to the valid-input mathematical claims. The interfaces have now been repaired and retested; the persisted diagnostic probes report the current behavior instead of requiring a defect to remain.

- **Unchecked query domain (correctness risk).** Initially `evaluate(summary,entry,lo)` had no inclusive upper domain argument. For `Rule(1,2,3)`, a block `[0]` summarized on `[2,3]` returned `1` for entry `4`, while the true exit is `2`. The containing pipeline checked membership only with an assertion. An explicit runtime domain check is necessary when summaries are public or assertions can be disabled.
- **Integer contract not enforced (contract risk).** Initially `Rule(0.5,2,3)` was accepted even though the residue and error proofs require integer arithmetic. Invalid dimensions and several malformed direct helper calls also reached arithmetic exceptions instead of a defined rejection. These are preventable boundary-validation gaps.
- **Display float conversion can abort valid exact calculation (robustness risk).** Initially `uniform_capacity_bound(Rule(1,2,1024),2,1,1)` raised `OverflowError` while converting an exact, finite capacity error bound to a display float. Exact rational proof fields should survive independently of optional displays. Moreover, comparing two rounded floats is not an exact verification of a claimed rational upper bound; capacity/enclosure comparisons should use the exact numerator and denominator.

The repaired summary is an immutable `MapSummary` that stores the original inclusive entry domain. Evaluation uses this stored domain and rejects conflicting optional domain arguments, preventing accidental domain substitution. This metadata binding protects ordinary use; it is not an authentication mechanism against deliberately fabricated summaries. The original tuple positions for base, mask and operation statistics remain stable.

## Remaining limits

The all-time derivation applies to the specified fixed complete groups. A reset must restart the unrounded predictor at the new exact state and restart the rounding-error origin, or be incorporated in a separately proved affine/reset model. Reusing a pre-reset carry after an externally changed state is invalid. Partial groups and coefficient changes need their own capacity calculation or a checked direct path. Per-instance certificates alone do not establish one universal hardware mask size.

The reference stores an integer with one bit per certified adjacent input boundary. Coarse precision and large unsigned domains can therefore require very large memory before a summary is usable. The repaired constructor defaults to a 65,536-bit software mask-width limit, rejects wider domains before performing the initial bit shift, and allows an explicit limit override. This guard is a resource limit for the reference program, not FPGA admission. An implementation that assumes one deletion, a fixed mask width, or bounded queues must admit configurations using a proved capacity bound before construction and establish intermediate widths, including the unrounded range `S` above `H`. Arbitrary-precision Python correctness does not certify RTL overflow behavior, timing, rank/select circuitry, buffering, or throughput.

A separate finite-precision interval tree or signed pipeline requires a fresh enclosure argument. Neither exhaustive small-state checks nor large randomized runs remove these scope conditions. No statistical result here warrants describing the overall research direction as ironclad.
